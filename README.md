# LexiVault Studio — 個人英語視覺詞庫與單字工坊

全新升級的純靜態單頁網頁應用程式（Zero-build Vanilla JS ES Modules），專為 **GitHub Pages** 部署打造，完整相容你原有的雙 Supabase 資料庫與 Storage 架構，無須修改任何資料表結構即可無縫接軌使用。

## ✨ 核心升級與新功能

1. **單頁統一架構（取代舊版雙 `<iframe>`）**
   - 原生整合「🖼️ 圖卡工坊」、「📚 單字長句」、「🎯 互動測驗」與「📊 學習洞察」，支援桌面頂部膠囊導覽與手機底部導覽列。
2. **極致效能與零遺漏載入**
   - 解決舊版一次發送數百個 DB 查詢與 30 筆分頁限制問題：採用並行批次載入全部圖卡（Storage + `flashcard_explanations`）與全部單字長句（`user_cards`），並搭配每批 40 張漸進渲染，搜尋與排序真正涵蓋整個詞庫。
   - 圖片載入移除不必要的 `?t=Date.now()` 破壞快取參數，大幅節省 Supabase 免費流量。
3. **跨庫連動與全域搜尋 (`Ctrl + K` / `/`)**
   - 命令面板一秒搜尋所有圖片詞彙、單字長句、群組與快捷動作。
   - 圖卡可一鍵複製至單字庫（`↗`）；單字卡可一鍵跳轉至圖卡工坊搜尋配圖（`🖼️`）。
4. **圖片搜尋與建卡工坊**
   - 內建 **Wikimedia Commons（免費無上限）** + **Google 圖庫** 雙引擎切換。
   - 拖放 / 多檔上傳 / `Ctrl + V` 剪貼簿貼圖，一律顯示美觀預覽彈窗（告別原生 `prompt()`），支援一鍵自動翻譯中文名與壓縮品質切換（省流量 `≤10KB` / 高畫質 `≤50KB`）。
5. **全新互動測驗競技場（Study Arena）**
   - **3D 翻轉記憶卡**（空白鍵翻面、`1/2/3` SRS 複習排程記錄）
   - **圖文四選一測驗**（支援看圖選詞 / 看詞選圖 / 英選中 / 中選英、連勝紀錄、錯題重練）
   - **聽音拼寫挑戰**（慢速語音、漸進字母提示、逐字拼寫比對）
   - **極速配對消除**（圖片與單字配對計時，記錄最佳成績）
6. **懸浮連續朗讀播放器（Audio Dock）**
   - 支援循環播放、可調次數與間隔、**中英雙語磨耳朵模式**，以及行動裝置 **Screen Wake Lock** 防休眠。
7. **雙帳號自動保活與資料匯出**
   - 延續 6 天自動輕量 Ping 保活機制（`integrated_learn_tools_last_activate`），並提供一鍵匯出 **JSON 完整備份 / CSV / Anki (.txt)**。

## 🚀 部署到 GitHub Pages

1. 將 `lexivault-web` 資料夾中的所有檔案推送到你的 GitHub repository（例如 `main` 分支根目錄）。
2. 在 GitHub Repository 的 **Settings → Pages → Source** 選擇 **GitHub Actions**（已內附 `.github/workflows/deploy-pages.yml` 與 `.nojekyll`）。
3. 推送後數十秒即可上線使用！

## ⌨️ 常用快捷鍵

- `Ctrl + K` 或 `/`：開啟全域快速搜尋命令面板
- `Alt + 1 ~ 4`：快速切換四大功能分頁
- `Ctrl + V`：在「圖卡工坊」直接讀取剪貼簿圖片並建卡
- `Space` / `1~4`：互動測驗翻卡或選擇作答
